# Smart Fashion — обновление 15 октября 2026

Проект переименован из SILK в Smart Fashion: логотип, metadata, favicon, каталог,
админка, документы, имена скачиваемых результатов. Технические ключи `silk:*` и
cookie `silk_admin` сохранены для совместимости с существующими данными.

Главная, каталог с поиском/фильтрами/готовыми комплектами, подборка, анкета и
примерка получили единый интерфейс. Выбор всех пяти слотов сохраняется при
переходе через анкету. Добавлены доступные диалоги, состояния загрузки/ошибок,
мобильная навигация и восстановление сохранённых вещей.

Добавлены политика конфиденциальности, условия, описание cookie, обязательное
версионированное согласие перед обработкой анкеты/генерацией. Необязательная
аналитика выключена до разрешения; отзыв прекращает будущие события и удаляет
идентификатор из браузера. API отклоняет запросы без нужного согласия до AI.

Контакт CTO: alimzhananuar69@gmail.com. Обращения по персональным данным сохраняются
в защищённой очереди админки. Изменение статуса обращения не удаляет файлы и не
отправляет email автоматически. Контакт и название оператора редактируются там же.

Проверено: 22 автоматических теста, ESLint, production build. В браузере проверены
главная, поиск, сохранение вещей, мобильное меню, cookie-настройки и документы,
переход из комплекта в анкету; ширины 390 и 1280 px. Новые тесты используют мок AI;
платные вызовы при этой итерации не выполнялись. Реальные FASHN/Gemini генерации
проверялись в предыдущем релизе (см. verification-2026-10-15.md).

При конкурентном запуске обнаружен SQLITE_BUSY с незавершёнными statements:
повтор миграции теперь создаёт новый клиент и использует ограниченные повторы.
Тест с шестью параллельными процессами прошёл после исправления.

Ограничения явно отражены в политике: изображения пока доступны по прямым URL,
автоматический срок удаления не настроен; внешние AI/облачные сервисы могут
обрабатывать данные за пределами РК. Документы не подтверждают соответствие всем
правовым требованиям или локализацию серверных данных в РК. Оператор указан как
проект Smart Fashion; юридические реквизиты организации не предоставлялись.
