# Проверка SILK — 15 октября 2026

## Проверено

- Основной сайт: главная, каталог, карточка товара, связанные товары,
  добавление вещи в примерочную и отображение сохранённой вещи.
- Локальная production-сборка: главная, каталог, карточка, анкета, примерка,
  примерочная, админка — HTTP 200. Каталог содержит 56 товаров; все 56
  основных фото доступны. API каталога, карточки, рекомендаций и образа
  отвечают успешно. API галереи без входа возвращает 401.
- В браузере: уведомление в начале анкеты, вход в админку, вкладки
  статистики и генераций, пустая галерея и карточки с тестовыми изображениями.
- `npm run lint` и `npm run build` проходят.
- `npm test`: 13 проверок, включая родительский сценарий. Используются
  временные базы и подмена ответов FASHN/Gemini; неожиданные сетевые запросы
  запрещены тестом. Проверены вход/выход, защита галереи, параметры и
  пагинация, сохранение сгенерированной модели, исключение личных фото,
  ошибки AI, сохранение примерок и истории, лимит, учёт расхода, серверные
  события, статистика за все периоды, бюджет, создание/редактирование/удаление
  товаров и образов. Отдельно проверен запуск миграций шестью процессами
  одновременно на пустой базе.
- Python-пайплайн: проверка синтаксиса `python3 -m py_compile
  scripts/process_photos.py`.

## Исправлено при проверке

- Абсолютные URL фото товаров из Vercel Blob портились при подготовке
  примерки: к ним добавлялся адрес сайта. Теперь адрес разрешается через URL.
- Одновременные процессы сборки могли конфликтовать при автоматических
  миграциях. Добавлен ограниченный повтор с перечитыванием журнала.
- Загрузка статистики нарушала правило lint для React effects. Устаревшие
  запросы теперь отменяются при переключении периода и выходе из вкладки.
- Анкета с одновременно переданными `no_photo` и файлом ошибочно отмечалась
  как сгенерированная в статистике. Источник определяется по фактической ветке.

## Что добавлено

В начале анкеты и перед примеркой показано уведомление о сохранении и
возможном просмотре результатов администраторами для улучшения работы сайта.
В `/admin` есть вкладка «Генерации»: результаты, тип, дата, профиль, образ,
фильтры, страницы и открытие оригинала. Существующая история примерок
используется без переноса файлов; новые модели по анкете учитываются отдельно.
Старые модели нельзя надёжно отличить от загруженных фотографий, поэтому
автоматического добавления старых `photo_path` в галерею нет.

## Границы проверки

В локальном окружении нет ключей Gemini/FASHN, Turso и Vercel Blob. Реальные
платные генерации, внешнее облачное хранилище и облачная база этими тестами
не проверены. Админка основного сайта требует действующий пароль; её данные
проверялись на изолированной локальной базе. Обработка новых фото каталога
через реальный Gemini не запускалась. Успех локальной сборки не подтверждает
доступность AI-провайдеров, их квот и баланса.

Галерея защищена паролем администратора. Существующий способ хранения
картинок использует публичные URL; добавление галереи не делает файлы приватными.
Скриншот галереи сделан локально на демонстрационных изображениях проекта.
