# apps/web

Next.js часть ZHIBEK. Инструкции по установке, запуску и обработке фото — в
[корневом README](../../README.md).

Быстрый старт из этой папки:

```bash
npm install
npm run dev
```

Команды: `npm run sync:catalog`, `npm run db:generate`, `npm run db:migrate`, `npm run db:studio`, `npm run lint`.
